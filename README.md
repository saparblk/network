# Network Monitoring

## Dashboard Monitoring

Project ini merupakan sistem monitoring jaringan yang dikembangkan untuk membantu memantau kondisi perangkat dan konektivitas jaringan secara real-time.

### Teknologi yang Digunakan

- Node-RED
- Grafana
- Network Monitoring
- SQL
- Ping Monitoring

### Fitur

- Monitoring konektivitas perangkat jaringan
- Monitoring status perangkat secara real-time
- Visualisasi data melalui dashboard Grafana
- Identifikasi perangkat yang mengalami gangguan koneksi
- Monitoring dan pencatatan status perangkat

### Peran Saya

Terlibat dalam pengembangan dan implementasi sistem monitoring, konfigurasi monitoring jaringan, troubleshooting, serta pembuatan dashboard untuk membantu pemantauan kondisi perangkat.

### Hasil Project

Sistem monitoring membantu mempermudah pemantauan kondisi perangkat dan mempercepat identifikasi ketika terjadi gangguan jaringan.
